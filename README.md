# NEET Preparation — Atomic Structure Study Desk

A responsive, single-file study web app that consolidates the five supplied **Structure of Atom** class-note PDFs into one revision workspace.

## Included topics

- Atomic number, mass number, subatomic particles, isotopes, isobars, isotones and isoelectronic species
- Cathode rays, anode/canal rays, Thomson and Rutherford models, Millikan’s experiment, X-rays and radioactivity
- Electromagnetic radiation, electromagnetic spectrum, black-body radiation and Planck’s quantum theory
- Photoelectric effect and Einstein’s equation
- Bohr model postulates, radius, velocity, energy levels, transitions and limitations
- Hydrogen spectrum, Rydberg equation, spectral series and spectral-line counting
- de Broglie matter waves and Heisenberg uncertainty principle
- Quantum-mechanical model, Schrödinger equation, wavefunctions, probability density and quantum numbers
- Orbital shapes, nodes, shell/subshell capacities, electronic configurations, Aufbau, Pauli and Hund rules
- Chromium/copper configurations and magnetic behaviour
- Formula vault, constants, quick revision lines and interactive practice questions

## Features

- Search across notes
- High-yield mode
- Responsive desktop and mobile layout
- Dark/light theme
- Mark core study modules complete (saved in the browser)
- Formula vault and instant-feedback multiple-choice practice
- Print or save notes as PDF from the browser

## Run locally

Open `index.html` in a modern browser. The app has no build step and no external runtime dependencies.

## GitHub Pages

The workflow in `.github/workflows/pages.yml` publishes the static site from the repository root on pushes to `main` and through manual workflow dispatch.

Live site (once deployment completes): https://juyel-dev.github.io/neet-preparation/

## Source and syllabus note

The notes were compiled from the five uploaded image-based class-note PDFs. Equations have been typeset for readability and symbols/units normalised. This is a revision companion, not a guarantee of the final NEET UG 2027 syllabus; cross-check the final official NTA bulletin when it is published.
